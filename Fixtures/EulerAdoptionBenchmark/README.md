# Shared Euler application adoption benchmark

Run `bash Scripts/check-euler-adoption.sh` from a clean committed candidate.
The frozen pre-adoption application is BombCAD 586ed4e4780267049beedd197cac2aa9cdd01ec0,
whose Euler source has blob 4736724d8bf71dd84ebb8bde48c0b10b7953a474 and SHA-256
d80e566a9938f665d71ee00bb813e934bb5febff1a112920200fd47560c818c5.
The script copies this identical fixture to that original without changing its
source/pin, and builds both optimized variants with identical flags.

Existing complete wall/piston/reflection and packet/remap/moving-reservoir reports
are retained. Additional native histories cover 24 ordered nonuniform tubes and
16 clipped grouped domains over all Euler/SSPRK2, uniform/pulse and selected
wall-speed/resolution/orientation combinations. Every accepted interval retains
input cells, actual reconstructed face/wall traces, replayed first/second stages,
complete final cells and ordered native wall impulse/work bits. Replay must
reproduce the actual app-owned limiter/group method's final result/load bits.
Grouped membership, full original native grid and actual scattered fields remain.
The public fractional pressure-pulse study's six cases also retain their full records.

The protected Core scalar checker at exact alpha.16 supplies independent SI,
EOS, per-cell flux, wall-traction, characteristic/geometric clock and extensive
budget checks. The app checker also verifies full staged means/load composition,
clock continuity, aggregation/scatter completeness and the exact dependency pins.
Fifteen deliberate corruptions must reject beyond paired equality. Existing wall
and packet corruption gates remain. These are numerical integration checks, not
empirical blast accuracy or extraction of geometry/reconstruction/time policy.
