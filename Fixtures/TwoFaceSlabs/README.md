# Slab test data

Derived data from two open-access papers, both under CC BY 4.0
(https://creativecommons.org/licenses/by/4.0/). The values are transcribed from the papers'
tables, text and drawings; nothing was digitised from plotted histories. `TwoFaceSlabTests`
(Sources/BlastCore/TwoFaceSlabTests.swift) holds the same values for `blastbench twoface`.

- `Wu2023.json`: Y. Wu et al., *Materials* 16, 4068 (2023), doi:10.3390/ma16114068.
- `Wang2022.json`: W. Wang et al., *Materials* 15, 6449 (2022), doi:10.3390/ma15186449.

See docs/validation.md, "Slabs with steel in both faces", for the comparison and the assumptions.
