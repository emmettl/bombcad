Eighth build of BombCAD, an interactive blast simulator for Macs: 0.5.0 with the four known
limitations its notes listed fixed, and nothing else new.

- macOS 15 or later, Apple silicon (arm64), Metal GPU
- Signed with a Developer ID and notarized by Apple, with the ticket stapled: it opens without
  Gatekeeper warnings
- Version 0.5.1, build 12, from commit —

**Fixed.** Each was found by a review of the code on 19 October, after 0.5.0 was built.

- **On the fine start (the default), events were timed from the hand-over** rather than from
  the detonation. The GPU's clock started at zero when the grid took over from the
  one-dimensional burst, so fragment holes and close-in breaches opened a few milliseconds late,
  envelope components' load histories were shifted by as much, and arrival times on the exposure
  plane stepped at the radius the start was mapped to. The clock now starts at the run's time;
  a test holes a pane at a set time on the fine start and checks it opens then.
- **Refined runs that vent glazing** left the last two pane cells shut on the fine grid when
  their panes broke, and when pane 0 broke they could open the fine cells of the domain's corner
  cell. The table of panes the fine grid reads was laid out 48 bytes long in Swift where the shader
  reads 32; it is now 32, and a test checks the two layouts agree.
- **Restarting a run with shells** started it with the springs' and fasteners' state from the run
  before, released or pulled through, and so did a run whose settling under its own weight did not
  converge. Each restart now puts them back as built; a test pulls a spring support off its edge,
  restarts, and pulls it off again.
- **A model with any timber in it** integrated all its shells, concrete slabs included, through
  their depth by timber's rule (3 to 5 points rather than 8), which moved their cracking and yield.
  Each shell now takes its own material's rule: models without timber shells are unchanged to the
  bit, and mixed ones, as the terraced row's brick walls beside its timber floors, move a little.
- **The check that stops a run whose wave speed is not a real positive number** is now written so
  that the compiler's fast arithmetic cannot drop it, as it could before, and the flame's
  wrinkling likewise; the seven recorded runs checked give the same result to the bit.

Also: a joint's friction that falls with pressure must now take an exponent below 1, where its
force still grows with pressure (the neoprene pad's is 0.20).

The rest is as [0.5.0](0.5.0.md): its features, its defaults and their standing, and its other
known limitations (thermal frames before the fine start's hand-over, and memory kept by each run
of a parameter sweep).

It is a study of the numerics, the physics and the performance of blast simulation, not a design
tool, and nothing in it should be used to judge the safety of a real structure. MIT licence.
