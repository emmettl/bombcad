**`blastmodel`, the CPU studies on Linux.** A command-line tool that builds without Metal, on a Mac
or on Linux, and runs the studies `scenebench` and `blastbench` run on the CPU:
- the façade surrogate's judge and extract;
- district glass and glass calibration;
- protective design;
- charge inference;
- the soil column and the half-space's calibration.

The same code backs both, and gives the same answers. GeoTIFF elevations compressed with Deflate
are read on Linux by a decoder written in Swift ([on Linux](../../linux.md)).
