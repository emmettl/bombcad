**Continue a run from a moment of its replay, at full detail.** A recorded run saves its full
state every eighth of the way (Settings ▸ Replay, "Space for saved states", 512 MB a run) and
wherever you choose Simulation ▸ Save State Here (⌥⌘S). Replaying it, the slider marks those
states and **Continue from …** takes back the one at the time shown or just before, then runs on
from there, the same to the bit as the run went, structures, envelopes and venting included; Keep
Run keeps the states with the run ([continuing a run](../../using-the-app.md#continuing-a-run-from-a-saved-state)).
Runs with fragments, ground points or thermal receivers, or whose delayed charges have begun to
fire, neither save nor continue yet, and a kept run continues only in its own scene and settings.
