**Run the blast on a Mac nearby and watch it here.** With a Mac paired (Settings ▸ Macs nearby),
**Run on** in the Run tab sends the blast to it: its GPU runs the air and the structures and sends
the scene as this Mac draws it, the field every few cells and every structure's mesh, and the
viewport shows each frame as it arrives. The run comes back kept, with the frames as its recording,
to scrub, replay and compare like a run made here. If the link drops, the run carries on there:
**Keep Watching** picks it up again, or **Fetch Result Later** collects it when it suits. Measured
with the Studio running and the mini watching over Wi-Fi, the city block's frames (every 4th cell,
about 1.2 MB) nearly all arrived, one every 0.2 s, about 0.2 s behind the run, for 4–6 ms of the Studio's
time each. Pause, edits mid-run and the fragments, thermal radiation, ground points and envelope
damage stay on the Mac showing the scene for now
([running on a Mac nearby](../../run-comparison.md#running-the-blast-on-a-mac-nearby),
[measured](../../distributed-computing.md#the-thin-client-in-the-app-21-october-2026)).
