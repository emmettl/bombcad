**Macs that share work all need 0.6.0 (worker protocol 15).** A worker, a Mac watching another's
run, and the Mac that shares a sweep or a run's companions must all be on this version: the
fireball's frames now carry the hot air's absorption and the 1-D shells, delayed charges travel
with the scene, and the materials' colours travel to a watched view. A nearby Mac on an earlier version
is listed as incompatible and is not sent work. A run kept with collapse's new standing cannot be opened by an app from
before this release.
