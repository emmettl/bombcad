# Data wanted

What would test the model and is not yet in hand, as things to do: documents to fetch in a
browser, datasets to ask their owners for, and, last, what has been fetched and where it is
used. The full survey behind this list, each source with what it would give and what was
searched, is in [Data survey](data-survey.md).

## To fetch

Open documents that this machine's scripts cannot download: the sites refuse automated access.
In a browser each is a click. Save each into the folder given, with a `SOURCE.md` beside it (the
citation, the link and the date), and tell a session it is there; nothing goes into the
repository. DTIC's links are the public PDFs as its listings gave them on 11 October 2026; if one
fails, search the number at [discover.dtic.mil](https://discover.dtic.mil/).

A cloud session tried every source below on 18 October 2026 and fetched none of them. Its
container's network policy refused every host but GitHub and the package registries (DTIC, OSTI,
ERDC, Zenodo, figshare, Mendeley Data, HathiTrust, Wikimedia, the universities' repositories and
the publishers alike), and its page reader could not resolve any host. Only web search worked, so
what it found are routes, not documents: corrected titles, direct links, open mirrors and prices,
each seen in search results but not opened. They are in the last column of each table, and in
full in the session's report, kept outside the repository at
`/Volumes/StudioData/bombcad/cloud-reports/2026-10-19/data-fetch.md`. Where a row says "not searched", the session's
allowance of 200 searches ran out first.
